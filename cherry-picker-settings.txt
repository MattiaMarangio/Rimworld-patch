CHERRY PICKER SETTINGS
======================

What was removed with Cherry Picker (by Owlchemist), saved so it does not have to be redone.
98 entries: 2 research projects, 64 items, buildings and weapons, 32 recipes.

HOW TO RESTORE
--------------
1. Quit RimWorld.
2. Copy everything between the two "----- RAW SETTINGS FILE -----" lines below into a file named
   Mod_3521312241_Mod_CherryPicker.xml
3. Put it in the RimWorld config folder:
   Mac:     ~/Library/Application Support/RimWorld/Config/
   Windows: %USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\Config\
   Linux:   ~/.config/unity3d/Ludeon Studios/RimWorld by Ludeon Studios/Config/
4. Start the game. Cherry Picker reads the list at startup.

Note: Unified Research Tree gives three items a new research because their original one
(Trench warfare) is removed here: trench gun and flamethrower -> Gunsmithing, razor wire -> Machining.
